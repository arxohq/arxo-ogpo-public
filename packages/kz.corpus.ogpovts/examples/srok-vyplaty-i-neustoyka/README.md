# Вовремя ли выплачено и сколько неустойки?

Пять самостоятельных дел над `kz.corpus.ogpovts@0.1.0` (Закон РК «Об
обязательном страховании ГПО владельцев транспортных средств», № 446-II) и
мостом `kz.corpus.strakhovaya_neustoyka@0.1.0` (статья 26 пункт 4 Закона →
статья 353 ГК РК → начисление `calc.accruals`). Нормы импортируются из
канонов; здесь только события дел, снимок официального календаря 2026 года
и сохранённые вопросы.

Делу предъявляются ДВА СОБЫТИЯ — день получения страховщиком документов
статьи 25 и день фактической выплаты. День истечения срока (пятнадцать
рабочих дней, статья 26 пункт 1), просрочку и размер неустойки выводит
право, а не вводит специалист. Это и есть операция первого пилота из
паспорта продукта: семь приёмочных случаев паспорта отвечены здесь пятью делами, одним
отказом и проверкой повтора.

## Сцены

Во всех делах страховая выплата — 730 000 тенге, делитель года — 365
(факт дела: статья 353 ГК способа перевода годовой ставки в дневную не
называет, и пакет его не подставляет).

| Дело (`--case`) | Что предъявлено | Ответ и основание |
|---|---|---|
| `VDenSroka` | Документы получены в среду 22.07.2026; выплата 12.08.2026 | срок истекает **12.08.2026** (15 рабочих дней по календарю, `GeneralPaymentDueDay`); просрочки **нет** (NEITHER); неустойка не выводится вовсе — ни нулём, ни суммой |
| `Prosrochka` | Те же документы; выплата в понедельник 24.08.2026 | просрочка **есть** (`PaymentMadeLate`: 24.08 > 12.08); неустойка **4 020 ₸** = 730 000 × 12 дней × 16,75 % / 365 (`DnevnayaStavka`, `RazmerNeustoyki`, ставка на день исполнения из снимка Национального Банка); обязанность уплатить неустойку **ACTIVE** |
| `CherezPrazdnik` | Документы получены 19.10.2026; выплата 10.11.2026 | срок истекает **10.11.2026**, а не 9-го: День Республики 25.10 пришёлся на воскресенье и перенесён на понедельник 26.10, оба дня в снимке нерабочие; выплата в срок |
| `BezDelitelya` | Факты `Prosrochka` без делителя года | просрочка есть, размер неустойки **не выводится**; `why_not` называет правило размера неустановленным, а не выдаёт число |
| `Protivorechie` | Факты `Prosrochka` плюс второй день выплаты 26.08.2026 по тому же требованию | документ **NON_EXECUTABLE**: `KEY_CONFLICT` §45.1/§196 у дня выплаты и нарушенное ограничение `SingleEndPerAccrual`; оракул не выбирает «более правдоподобную» дату |

Седьмой случай паспорта — «требование вне согласованного покрытия» — не
дело, а вопрос: уменьшение неустойки судом (статья 297 ГК) в мире дела не
формализовано, и вопрос о нём отвергается статически (`LDC-E1105`,
символ не экспортирован), а не отвечается молчанием. Восьмой — «повтор на
закреплённых входах» — делает `check.py` для каждого вопроса: ответ Rust,
ответ Python-оракула, replay сохранённого расчёта и сохранённые байты
обязаны совпасть.

Независимые ожидания посчитаны по тексту статей 25 и 26 Закона, статьи 353
ГК, снимку календаря и решениям Национального Банка (16,75 % с 27.07.2026,
16,25 % с 07.09.2026) — не по ответам движка. Число дней просрочки в
`Prosrochka`: 13…24 августа включительно = 12; движку окно предъявляется
полуинтервалом [12.08, 24.08) — дней в нём столько же, а календарная
политика, которой статья 353 не устанавливает, ему не нужна.

## Две границы, найденные делами

- **Обязанность-срок `InsurerMustPayWithinTerm` — закрыто DECISION-0340 (20.09.2026).** До решения
  позиция оставалась UNDETERMINED: каркас читал `insurance_payment_made(demand)`, а дело подавало
  день выплаты. Теперь день выплаты влечёт факт исполнения, и позиция `SATISFIED` в обоих делах.
  Осталась граница ядра, записанная в том же решении открытым вопросом к SPEC: факт результата
  без даты делает обязанность `SATISFIED` и при выплате после срока — о просрочке говорит
  `payment_made_late`, а не статус обязанности.
- **`why_not` в `BezDelitelya` называет правило `RazmerNeustoyki`, а не
  пропущенный делитель**: блокер показывает несвязанные переменные первого
  уровня, а недостающая посылка `prinyatyy_delitel_goda` лежит двумя
  правилами глубже (`DnevnayaStavka` → `daily_rate`). Ответ верен — размер
  не выводится, — но «какого факта не хватает» он не говорит.

## Запуск в репозитории канона

В репозитории канона ОГПО подборка лежит в
`packages/kz.corpus.ogpovts/examples/srok-vyplaty-i-neustoyka` вместе со своим
миром: CLIR зависимостей — в `deps/`, снимок официального календаря — в
`resources/`, и то и другое закреплено `law.lock`. Бинарь — закреплённый
`law-cli` (как его получить — в README корня репозитория):

```sh
"$tools/law-cli" ask packages/kz.corpus.ogpovts/examples/srok-vyplaty-i-neustoyka --case Prosrochka --query-json packages/kz.corpus.ogpovts/examples/srok-vyplaty-i-neustoyka/queries/neustoyka-4020.json
python3 packages/kz.corpus.ogpovts/examples/srok-vyplaty-i-neustoyka/check.py --law "$tools/law-cli"
```

Здесь `check.py` сверяет ответы, основания и replay закреплённого `law-cli`;
побайтной сверки с Python-оракулом нет — оракул есть только в checkout
монорепозитория, для которого написаны команды ниже.

## Запуск из корня checkout монорепозитория

Восстановите зависимости по существующему `law.lock` (Python 3.12 или новее;
пятнадцать CLIR, включая замыкание ГК, ставок и вычислителей):

```sh
python3 packs/examples/cases/materialize_deps.py corpus/laws/kz/laws/ogpo-vts/examples/srok-vyplaty-i-neustoyka
```

Просрочка и неустойка:

```sh
./law ask corpus/laws/kz/laws/ogpo-vts/examples/srok-vyplaty-i-neustoyka \
  --case Prosrochka \
  --query-json corpus/laws/kz/laws/ogpo-vts/examples/srok-vyplaty-i-neustoyka/queries/neustoyka-4020.json \
  --out corpus/laws/kz/laws/ogpo-vts/examples/srok-vyplaty-i-neustoyka/runs/prosrochka-4020
```

Замените `Prosrochka` на `VDenSroka`: тот же вопрос ответит `NEITHER`.
Собственный вопрос — день истечения срока:

```sh
./law ask corpus/laws/kz/laws/ogpo-vts/examples/srok-vyplaty-i-neustoyka \
  --case CherezPrazdnik \
  --query 'evaluate collect day: Date where kz.corpus.ogpovts::payment_due_day(demand: entity_ref("urn:example:ogpo:trebovanie"), day: day);' \
  --query-id srok
```

Позиции дела (`queries/positions.json`) показывают обязанность уплатить
неустойку статьи 26 пункта 4; `queries/pochemu-net-neustoyki.json` в деле
`BezDelitelya` — блокер размера. В `result.json` → `proofGraph` видны
применения правил обоих канонов; их якоря на текст закона и ГК — в
`request.json` → `ir.nodes` → `anchors`.

Повтор сохранённого расчёта без чтения исходников пакета:

```sh
./law eval corpus/laws/kz/laws/ogpo-vts/examples/srok-vyplaty-i-neustoyka/runs/prosrochka-4020
```

Полная проверка подборки — шестнадцать вопросов, один отказ, основания,
Rust/Python побайтно и replay:

```sh
python3 corpus/laws/kz/laws/ogpo-vts/examples/srok-vyplaty-i-neustoyka/check.py
```

`deps/` и `runs/` в Git не хранятся. Пересоздать лок при обновлении
зависимостей: `./law engine lock <пакет> --clir corpus/clir --calendar corpus/clir/kz-official-calendar-2026.lawir.json --plain-descriptors -o <пакет>/law.lock`.
