# `vocab.maintenance`

Общий словарь измеряемого обслуживания для `renovation.*` и `vehicle.*`.
Он задаёт только представление замера, доказательства, события, ворот и
отступлений; `ReadinessOutcome` — конечный домен результата прикладного моста.

Здесь нет норм, источников, порогов, выбора единицы, календарной политики и
вывода готовности. Значение замера остаётся размерной `Quantity`; его единицу
задаёт предъявленный факт и проверяет потребляющий пакет. `vocabulary.json` —
единственный источник данных, `tools/gen_vocabulary.py --check` проверяет
порожденный `package.law`.
